# 北京浮生记 · 浏览器移植版

**[▶ 打开即玩](https://cantoblanco.github.io/beijing_fushengji/)**

基于郭祥昊 / Guoly 工作室的《北京浮生记 v1.2.2》原始 C++ 源代码移植。无需下载、安装或登录；GitHub Pages 纯静态托管，无后台、无第三方运行时依赖。原 PC 源码和资源保持不变，网页版位于 `docs/`。

## 保留的内容

- 40 天完整流程；8 类商品的价格区间、缺货、买卖、整数平均成本、容量与声誉。
- 10 个地铁站与 10 个地面地点；切换地图不扣天，重复到同一编号地点不扣天，与原程序一致。
- 18 条商业新闻、12 条健康事件、7 条财产事件；沿用原始事件文字、触发顺序和概率算法。
- 高利贷日息 10%、银行日息 1%、邮局还债、医院、强制住院、债务殴打、黑客银行事件。
- 租房中介的隐藏收费、100→140 容量上限、网吧三次限制、机场原版预告。
- 最后两日全品类市场、最后一天自动清仓、净资产结算、本地前十高分榜及名声评级。
- 原始 WAV 音效、图标、新闻/日记图片、故事、20 条提示、完整原版帮助、北京介绍、作者信息、特别声明和“老板来了”工作文档。

## 网页适配说明

规则以实际 C++ 行为为准：初始债务 5000 元，初始化计息后显示 **5500 元**（旧开场另有 5400 元笔误）；每次卖出禁书扣 7 名声、假酒扣 10；治疗每点 3500；网吧实际只能访问 3 次。租房广告不等于最终扣款，原作的中介额外收费保留。

原作 `RandomNum(n)` 是 `rand()%n`；网页保持各次取值范围、事件判定、顺序与计算公式，随机数源替换为浏览器 `Math.random()`，不承诺与某个 Windows `rand` 种子产生同一序列。C++ 整数除法/截断保留。只修复平台无意义或未定义的行为：无效输入、结束后重复操作、零数量除零和末日越界；名声评级按原作明确分段，纠正 `<20 >=10` 的 C++ 连写比较笔误。

排行榜保存在当前浏览器的 `localStorage`，等同原来的本地 `score.txt`，不是联网榜单。原作没有游戏存档，本版不增加自动存档或跨设备同步。浏览器要求音效在用户交互之后播放，默认不静音。部分原版网吧外链服务已经消失，保留为历史文字，不将玩家自动导航至失效或易主站点。机场原版只是未来版本预告，不是可飞行玩法；本版同样如此。老板文档的存盘改为浏览器下载文本。

## 开发与验证

```sh
npm test
npm run serve
# http://localhost:8765
```

无需 npm install。`tests/engine.test.js` 覆盖交易、利息、还债、容量、名声、住院扣天、盗窃截断、18 条商业事件、末日清仓以及 100 局确定性模拟。

`tools/extract-original.py` 从原始 GBK C++/RC 及帮助文件重建 UTF-8 数据、原图和音效（仅开发时需 Python 3 + Pillow）。原始文件不改动。GitHub Pages 使用 `master` 分支的 `/docs`，不需要 Actions 构建和第三方 CDN。
